# فلتر حصن — Hisn Filter

أداة مجانية مفتوحة المصدر، وقف لوجه الله، تحمي المسلم والأسرة من المحتوى المخالف على كل الأجهزة:
تضبيب العورات وصور النساء، وحجب الألفاظ والنصوص الإباحية، وحجب المواقع الإباحية، وإزالة الموسيقى.

A free, open-source content filter for Muslims and families. Everything runs on the device:
no server, no account, no data collection.

## المبادئ

- كل الفحص على جهاز المستخدم، ولا يُرسل أي محتوى لأي جهة.
- لا حساب، ولا تسجيل، ولا تقارير، ولا إحصاءات.
- الشك يُحجب: المحتوى يبقى مضبّبًا حتى يثبت أنه سليم.
- مجاني دائمًا، بلا إعلانات ولا اشتراكات.

## هيكل المشروع

| المجلد | المحتوى |
| --- | --- |
| `packages/core` | "العقل المشترك": تطبيع النص العربي، ومحرك الألفاظ، وسياسة المحتوى. يُستخدم في كل المنتجات |
| `apps/extension` | إضافة المتصفح، مبنية على كود HaramBlur (انظر `NOTICE.md`) |
| `apps/android` | تطبيق أندرويد (المرحلة 3) |
| `apps/ios` | تطبيق آيفون وإضافة Safari (المرحلة 4) |
| `docs` | الخطة والأدلة |

## التشغيل والاختبار

```bash
npm test          # يشغّل اختبارات packages/core
```

يحتاج Node.js 20 أو أحدث، ولا يحتاج أي مكتبات خارجية.
