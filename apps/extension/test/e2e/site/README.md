# ملفات الاختبار / Test fixtures

صور ومقاطع الاختبار (أشخاص وموسيقى) غير منشورة هنا، لأن حقوقها ليست لنا. ضع ملفاتك بالأسماء التي تذكرها الاختبارات
(`woman.jpg`، `man.jpg`، `test-video.webm`…) لتشغيلها محليًا.

The test images and clips (people, music) are not published here because we don't own their rights. Add your own files
with the names the tests reference (`woman.jpg`, `man.jpg`, `test-video.webm`, …) to run them locally.
