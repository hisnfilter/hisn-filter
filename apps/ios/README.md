# فلتر حصن — آيفون وآيباد

آبل لا تسمح لأي تطبيق بتغطية المحتوى داخل التطبيقات الأخرى، لذلك الحماية على آيفون من هذه الطبقات:

| الطبقة | ماذا تفعل | الهدف |
|---|---|---|
| ٠. التصفح المحمي | يوتيوب وإنستغرام وتيك توك وإكس وفيسبوك وقوقل داخل حصن، بنفس كود الإضافة (`dist/web/content-app.js` في عالم معزول، ومحرك الكشف في صفحة مخفية `pages/detector-app.html`)، مع حجب المواقع والبحث الآمن ويوتيوب المقيّد. إزالة الموسيقى المباشرة لم تُدعم فيه بعد | `ProtectedBrowser.swift` |
| وضع الطفل | زر واحد: حماية العقيدة، وإخفاء الشتائم، ويوتيوب المقيّد، وفلتر آبل، وقفل التطبيقات الأصلية ليتصفحها الطفل من «التصفح المحمي» فقط | `HomeView.swift` + `Shields` |
| ١. إضافة Safari | نفس إضافة الحاسوب: تضبيب الصور والفيديو، وإخفاء الألفاظ، وحجب المواقع، والبحث الآمن | `HisnSafari` (كودها في `apps/extension`) |
| ٢. فلتر آبل للمواقع | يحجب المواقع الإباحية في Safari وكل متصفح داخل التطبيقات (ManagedSettings) | التطبيق |
| ٣. حجب التطبيقات | يحجب تيك توك وإنستقرام وغيرها (يختارها المستخدم)، فيستخدم نسخها في Safari المحمية. سماح مؤقت 15 دقيقة بالرمز | التطبيق + `HisnMonitor` |
| ٤. شاشة الحجب | شاشة حصن بالعربية فوق التطبيق المحجوب، بزر «إغلاق» و«تخطي» | `HisnShieldConfiguration` + `HisnShieldAction` |
| ٥. فحص الشاشة (تجريبي) | بزر تسجيل الشاشة: يفحص الشاشة على الجهاز (عري عبر SensitiveContentAnalysis من آبل، ووجوه النساء عبر Vision ونموذج FaceRes)، وإذا وجد مخالفة غطّى التطبيقات المراقبة بشاشة حصن فورًا | `HisnBroadcast` |

لا خوادم، ولا حسابات، ولا يُحفظ أو يُرسل شيء.

## البناء (على الماك)

1. ثبّت Xcode من App Store، و[Homebrew](https://brew.sh)، ثم: `brew install xcodegen node`
2. ابنِ إضافة Safari:
   ```
   cd apps/extension && npm install && npm run build -- safari
   ```
3. الحساب مضبوط في `apps/ios/project.yml`: الفريق `2QGUC9PT86` (Mawaama Company Holding)، والمعرّف `com.muwamah.hisnfilter`.
4. ولّد المشروع وافتحه:
   ```
   cd apps/ios && xcodegen && open HisnFilter.xcodeproj
   ```
5. وصّل الآيفون، واختر هدف `HisnFilter`، ثم ▶ Run.
   - أدوات وقت الشاشة تعمل على جهازك للتجربة **قبل** موافقة آبل؛ الموافقة مطلوبة لـ TestFlight والمتجر.
   - App Group: فعّل `group.<BUNDLE_PREFIX>.hisnfilter` لكل الأهداف (يفعّله Xcode تلقائيًا مع التوقيع التلقائي).

## أول تشغيل على الآيفون

1. افتح التطبيق، واختر المستخدم والمستوى.
2. فعّل إضافة Safari (الخطوات داخل التطبيق: الإعدادات ← Safari ← الإضافات ← فلتر حصن ← جميع المواقع: السماح).
3. «السماح لفلتر حصن باستخدام وقت الشاشة».
4. اختر التطبيقات المحجوبة (اقتراح: تيك توك، إنستقرام، سناب) واستخدم نسخها في Safari.
5. (اختياري) فحص الشاشة: فعّل «تحذير المحتوى الحساس» في الإعدادات ← الخصوصية والأمن، واختر التطبيقات المراقبة، ثم ابدأ الفحص من الزر.
6. ضع رمز القفل.

## حدود يجب معرفتها

- فحص الشاشة **تجريبي**: يتوقف إذا أوقف المستخدم التسجيل، ويظهر الشريط الأحمر للتسجيل أعلى الشاشة، وحد ذاكرة الامتداد 50MB.
- فحص الشاشة يحجب **التطبيق كله** لحظة المخالفة (آبل لا تسمح بتغطية جزء منه)؛ زر «تخطي» يرفع الحجب ثانيتين لتنتقل للمقطع التالي.
- كشف العري في فحص الشاشة من آبل، ويحتاج تفعيل «تحذير المحتوى الحساس».
- السماح المؤقت أقل مدته 15 دقيقة (حد آبل لجداول المراقبة).
- بُني على ماك (Xcode، محاكي iPhone 18 Pro بنظام iOS 27) ونجح: التصفح المحمي يغطي النساء جزئيًا في صور قوقل. بقيت التجربة على جهاز حقيقي.

## أدوات

- `tools/tfjs_to_coreml.py`: يحوّل نموذج FaceRes إلى Core ML (يعمل على أي جهاز).
- `tools/verify_coreml.py`: على الماك، يقارن Core ML بنموذج ONNX.
- `tools/swift-syntax/`: فحص صياغة Swift بلا ماك.
